# ADR 0002 — 产品命名：准时 / Zhunshi

- 状态：已接受
- 日期：2026-07-01

## 背景
仓库与内部代码沿用 "flow" 作为工作名，但 "flow" 作为**对外品牌名**过于泛滥（大量产品同名），不适合作为应用名称。需要一个独特、易于上口、好记、可长期拥有的品牌名。

关键区分（见 `constitution/01-domain-model.md` 与命名讨论）：**品牌名**与**领域单位名词**是两件事，可分别决定。

## 决策
- **品牌名 = 准时（Zhunshi）**。
- **领域单位名词继续用小写 `flow`**（"创建一个 flow"）——通用名词不涉商标，改动最小。
- **仓库名 `flow` 保持不变**；代码里的类型仍是 `Flow / Run / Node`。
- App 显示名在 Phase 0 搭建时设为"准时 / Zhunshi"。

## 理由
- **语义契合创始场景**：创始场景是"患者按时服药"，"准时"直接编码了产品承诺（按时做该做的事），并可推广到烹饪/实验等"每一步都在对的时间发生"。
- **命名空间干净**：经四轮联网核查（见下），Zhunshi 是唯一没有任何软件公司/App/品牌同名的候选。
- 唯一代价：`zh` 声母对非中文用户略难念；`zhunshi.com` 已被注册（真实词常态，但背后无品牌），实操用 `zhunshi.app` 等变体即可。

## 被否决的方向（附证据）
命名的核心教训：**2026 年全球 App 命名空间里，任何"好念的 4–5 字母短 token"基本都被占了；越短越好念越是红海。干净的名字藏在稍长、拼法不那么大众的词里。**

- **英文常用/时间词**（Flow、Cadence、Tempo、Kairos…）：全部拥挤。
- **英文造词近时间词根**（Kadence/Rivo/Tempora/Runnel…）：几乎全被占；Kairo/Cairn 甚至在时间/效率品类正面撞车。
- **可爱常用拼音**（Kaishi/Paopao/Tuanzi/Nuannuan/Tiaotiao…）：全被占或撞大牌（Huohou=小米厨具、Tiaotiao≈头条）。
- **造词/叠音拟声**（Tita/Tada/Tiko/Bibo/Nabu/Youyou…）：六个全被占，Tita/Tada 直撞效率品类。
- **其他语义拼音**：Anshi（按时）有国企同名；Yibu（一步）仅工业同名、作为次选；**Zhunshi（准时）最干净**。

## 影响
- Phase 0 起，App 显示名/元数据使用"准时 / Zhunshi"。
- 正式注册前应做一次专业商标检索（届时另记）。
- 这是产品级命名决策，后续若更名需新增 ADR。
