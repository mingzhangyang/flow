# 「准时」隐私政策

> 本文陈述的事实以代码为准：本地优先（C6）、无账号、无遥测。
> 可发布版本（中英双语 HTML）在 `site/privacy/`，仓库设置里启用
> GitHub Pages（Source: GitHub Actions）后即托管于
> `https://mingzhangyang.github.io/flow/privacy/`。本文与 HTML 同步修订。

**生效日期**：2026-07-03（如商店提交日更晚，以提交日为准并同步更新此处）

「准时」（Zhunshi，下称"本应用"）是一款本地优先的时间模式工具。我们的隐私立场可以概括为一句话：**你的数据只在你的设备上，我们没有服务器，也收不到它。**

## 一、我们收集什么

**不收集任何数据。** 本应用：

- 没有账号系统，无需注册或登录；
- 没有自建服务器，不上传你的任何内容；
- 不接入任何统计、广告或行为追踪 SDK。

## 二、数据存放在哪里

你创建的 flow（流程定义）、运行记录、打卡日志、应用设置，全部存放在**你设备的本地存储**中。卸载应用即删除全部数据。你可以随时通过「分享 / 导出」把数据以开放格式（JSON）带走。

## 三、AI 生成功能（可选）

「AI 生成」是可选功能，由**你自己配置的模型服务**驱动（如 Anthropic、DeepSeek 或本地 Ollama 等任何兼容服务）：

- 使用该功能时，**你输入的描述文本**会从你的设备直接发送到你所选择的模型服务商，用于生成 flow 草稿；发送行为仅在你点按「生成草稿」时发生；
- 你的 **API 密钥只保存在本机**，绝不经由我们的任何服务器（我们也没有服务器）；
- 该请求受你所选服务商的隐私政策约束（例如 Anthropic、DeepSeek 各自的条款）；选择本地模型（如 Ollama）时，数据不离开你的网络；
- 不使用 AI 生成功能，则没有任何数据离开设备。

## 四、通知权限

本应用请求通知权限，仅用于在你设置的时刻发出**本地提醒**（如计时结束、服药时间）。提醒完全在设备本地调度，不涉及推送服务器。

## 五、健康相关内容的说明

本应用可用于服药提醒等场景。所有相关内容均为**你自己录入或导入的描述性信息**，本应用不提供医疗建议、诊断或处方；请以医嘱为准。这些信息与其它数据一样仅存于本机。

## 六、儿童隐私

本应用不面向 13 岁以下儿童设计，且因不收集任何数据，不存在儿童数据收集问题。

## 七、政策变更

如未来功能变化导致本政策调整（例如新增可选的云同步），我们会在应用更新说明中明确告知，并坚持"默认本地、上云可选"的原则。
